# Footnote Talent — CA / CS / Tax recruitment website (version 2)

Double-click `index.html` to open. Everything (photos, videos, animation libraries) is stored locally; only the Google Fonts load from the internet.

```
index.html
assets/
  css/style.css        styles — 60-30-10 palette tokens at the top (evergreen / cream / lime)
  js/main.js           video autoplay, parallax, scroll reels, stacked cards, forms
  js/vendor/           gsap, ScrollTrigger, lenis
  images/              14 photos (Unsplash licence)
  video/               7 clips, 720p (Mixkit free licence) + posters/
```

Before launch: replace brand name, email/phone and service promises; connect both forms (`#fFirm`, `#fCand` in main.js) to a backend or email service.
